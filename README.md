# Convalis House Website Prototype

Static one-page client website prototype inspired by the supplied editorial design.

## Preview

Open `index.html` in a browser.

Or run:

```bash
npm run dev
```

Then visit `http://localhost:3000`.

## Deploy On Vercel

Create a Vercel project with this folder as the project root.

- Framework preset: Other
- Build command: leave empty
- Output directory: `.`

The site uses local image assets only, so it does not rely on remote image URLs.
